<h2>Монадические операции в C++23: std::expected, std::optional, std::variant и другие</h2>

<p>
В C++23 были добавлены <strong>монадические операции</strong> для нескольких контейнеров и типов, что позволяет удобно обрабатывать цепочки операций, которые могут завершиться ошибкой или отсутствием значения.
Эти операции вдохновлены концепциями функционального программирования и предоставляют более выразительный и безопасный способ работы с данными.
</p>

<a id="introduction"></a>
<h3>1. Введение в монадические операции</h3>

<h4>Что такое монадические операции?</h4>
<p>
Монадические операции — это методы, которые позволяют:
</p>
<ul>
  <li><strong>Цепочки операций</strong> — последовательно применять функции к результату, обрабатывая ошибки или отсутствие значений на каждом этапе.</li>
  <li><strong>Трансформация значений</strong> — преобразовывать результат или ошибку.</li>
  <li><strong>Композиция операций</strong> — комбинировать несколько операций в одну.</li>
  <li><strong>Удобная обработка ошибок</strong> — избегать явных проверок на каждом шаге.</li>
</ul>

<h4>Основные монадические операции</h4>
<table>
  <tr>
    <th>Операция</th>
    <th>Описание</th>
    <th>Применимость</th>
  </tr>
  <tr>
    <td><code>and_then</code></td>
    <td>Если контейнер содержит значение, применяет функцию к этому значению. В противном случае возвращает ошибку или пустое состояние.</td>
    <td><code>std::expected</code>, <code>std::optional</code></td>
  </tr>
  <tr>
    <td><code>or_else</code></td>
    <td>Если контейнер содержит ошибку или пусто, применяет функцию к ошибке или создаёт значение по умолчанию.</td>
    <td><code>std::expected</code>, <code>std::optional</code></td>
  </tr>
  <tr>
    <td><code>transform</code></td>
    <td>Применяет функцию к значению, если оно есть. В противном случае возвращает ошибку или пустое состояние.</td>
    <td><code>std::expected</code>, <code>std::optional</code>, <code>std::variant</code></td>
  </tr>
  <tr>
    <td><code>transform_error</code></td>
    <td>Применяет функцию к ошибке, если она есть. В противном случае возвращает значение.</td>
    <td><code>std::expected</code></td>
  </tr>
  <tr>
    <td><code>value_or</code></td>
    <td>Возвращает значение, если оно есть, или значение по умолчанию.</td>
    <td><code>std::optional</code>, <code>std::expected</code></td>
  </tr>
  <tr>
    <td><code>visit</code></td>
    <td>Применяет функцию к значению в зависимости от его типа.</td>
    <td><code>std::variant</code></td>
  </tr>
</table>

<a id="expected_monadic"></a>
<h3>2. Монадические операции в std::expected</h3>

<p>
<strong>`std::expected<T, E>`</strong> — контейнер, который может содержать либо результат типа <code>T</code>, либо ошибку типа <code>E</code>.
Монадические операции позволяют удобно обрабатывать цепочки операций, которые могут завершиться ошибкой.
</p>

<h4>Основные монадические операции</h4>
<table>
  <tr>
    <th>Операция</th>
    <th>Синтаксис</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>and_then</code></td>
    <td><code>expected.and_then(f)</code></td>
    <td>Если <code>expected</code> содержит значение, применяет функцию <code>f</code> к этому значению. В противном случае возвращает ошибку.</td>
  </tr>
  <tr>
    <td><code>or_else</code></td>
    <td><code>expected.or_else(f)</code></td>
    <td>Если <code>expected</code> содержит ошибку, применяет функцию <code>f</code> к этой ошибке. В противном случае возвращает значение.</td>
  </tr>
  <tr>
    <td><code>transform</code></td>
    <td><code>expected.transform(f)</code></td>
    <td>Применяет функцию <code>f</code> к значению, если оно есть. В противном случае возвращает ошибку.</td>
  </tr>
  <tr>
    <td><code>transform_error</code></td>
    <td><code>expected.transform_error(f)</code></td>
    <td>Применяет функцию <code>f</code> к ошибке, если она есть. В противном случае возвращает значение.</td>
  </tr>
</table>

<a id="optional_monadic"></a>
<h3>3. Монадические операции в std::optional</h3>

<p>
<strong>`std::optional<T>`</strong> — контейнер, который может содержать значение типа <code>T</code> или быть пустым.
Монадические операции позволяют удобно обрабатывать цепочки операций, которые могут завершиться отсутствием значения.
</p>

<h4>Основные монадические операции</h4>
<table>
  <tr>
    <th>Операция</th>
    <th>Синтаксис</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>and_then</code></td>
    <td><code>optional.and_then(f)</code></td>
    <td>Если <code>optional</code> содержит значение, применяет функцию <code>f</code> к этому значению. В противном случае возвращает пустой <code>optional</code>.</td>
  </tr>
  <tr>
    <td><code>or_else</code></td>
    <td><code>optional.or_else(f)</code></td>
    <td>Если <code>optional</code> пуст, применяет функцию <code>f</code> (которая должна возвращать <code>optional</code>).</td>
  </tr>
  <tr>
    <td><code>transform</code></td>
    <td><code>optional.transform(f)</code></td>
    <td>Применяет функцию <code>f</code> к значению, если оно есть. В противном случае возвращает пустой <code>optional</code>.</td>
  </tr>
</table>

<a id="variant_monadic"></a>
<h3>4. Монадические операции в std::variant</h3>

<p>
<strong>`std::variant<Ts...>`</strong> — контейнер, который может содержать значение одного из нескольких типов.
Хотя <code>std::variant</code> не имеет монадических операций в том же смысле, что <code>std::expected</code> или <code>std::optional</code>, его можно использовать с <code>std::visit</code> для обработки всех возможных типов.
</p>

<h4>Основные операции</h4>
<table>
  <tr>
    <th>Операция</th>
    <th>Синтаксис</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>std::visit</code></td>
    <td><code>std::visit(visitor, variant)</code></td>
    <td>Применяет визитор (функцию или лямбду) к значению в <code>variant</code> в зависимости от его типа.</td>
  </tr>
  <tr>
    <td><code>transform</code> (C++23)</td>
    <td><code>variant.transform(f)</code></td>
    <td>Применяет функцию <code>f</code> к значению, если оно есть. Возвращает новый <code>variant</code> с результатом.</td>
  </tr>
</table>

<h4>Примеры использования</h4>

<h5>Пример 1: std::visit</h5>

<h5>Пример 2: Цепочка операций с std::visit</h5>

<h4>Рекомендации по выбору контейнера</h4>
<ul>
  <li><strong>std::expected</strong> — используйте для операций, которые могут завершиться ошибкой.</li>
  <li><strong>std::optional</strong> — используйте для значений, которые могут отсутствовать.</li>
  <li><strong>std::variant</strong> — используйте для значений, которые могут быть одного из нескольких типов.</li>
  <li><strong>std::unique_ptr</strong> — используйте для динамического управления памятью.</li>
  <li><strong>Ranges</strong> — используйте для работы с последовательностями данных.</li>
</ul>

<a id="conclusion"></a>
<h3>8. Заключение</h3>

<p>
<strong>Монадические операции</strong> в C++23 предоставляют удобные средства для обработки цепочек операций, которые могут завершиться ошибкой или отсутствием значения.
Они доступны для <code>std::expected</code>, <code>std::optional</code> и частично для <code>std::variant</code>.
</p>

<p>
Эти операции позволяют:
</p>
<ul>
  <li>Создавать цепочки операций без явных проверок на каждом шаге.</li>
  <li>Удобно обрабатывать ошибки и отсутствие значений.</li>
  <li>Писать более выразительный и безопасный код.</li>
</ul>

<p>
Хотя не все контейнеры поддерживают монадические операции напрямую, их можно эмулировать с помощью лямбд и функций.
В будущих версиях C++ ожидается расширение поддержки монадических операций для других типов.
</p>
