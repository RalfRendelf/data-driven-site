<h2>std::numeric: Числовые утилиты в C++</h2>

<p>
<strong>`std::numeric`</strong> — набор утилит для работы с числами, доступный в стандартной библиотеке C++.
Включает функции для вычисления наибольшего общего делителя (НОД), наименьшего общего кратного (НОК), и других математических операций.
</p>

---
<h3>Теоретические основы</h3>

<h4>Основные функции</h4>
<table>
  <tr>
    <th>Функция</th>
    <th>Описание</th>
    <th>Стандарт</th>
  </tr>
  <tr>
    <td><code>std::gcd</code></td>
    <td>Вычисляет наибольший общий делитель (НОД) двух чисел.</td>
    <td>C++17</td>
  </tr>
  <tr>
    <td><code>std::lcm</code></td>
    <td>Вычисляет наименьшее общее кратное (НОК) двух чисел.</td>
    <td>C++17</td>
  </tr>
  <tr>
    <td><code>std::midpoint</code></td>
    <td>Вычисляет середину между двумя числами, избегая переполнения.</td>
    <td>C++20</td>
  </tr>
  <tr>
    <td><code>std::lerp</code></td>
    <td>Линейная интерполяция между двумя числами.</td>
    <td>C++20</td>
  </tr>
</table>

<h3>Практические рекомендации</h3>
<ul>
  <li>Используйте <code>std::gcd</code> и <code>std::lcm</code> для работы с целыми числами.</li>
  <li>Используйте <code>std::midpoint</code> для вычисления середины между двумя числами без риска переполнения.</li>
  <li>Используйте <code>std::lerp</code> для линейной интерполяции.</li>
</ul>

---
<h3>Заключение</h3>
<p>
<strong>`std::numeric`</strong> — это набор утилит для работы с числами в C++.
Она предоставляет функции для вычисления НОД, НОК, середины между числами и линейной интерполяции.
</p>
