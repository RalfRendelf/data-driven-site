<h2>std::any: Хранение значения любого типа</h2>

<p>
<strong>`std::any`</strong> — контейнер, введенный в C++17, который может содержать значение любого типа.
Он предоставляет механизм для хранения и извлечения значений произвольных типов с использованием <strong>type erasure</strong>.
</p>

---
<h3>Теоретические основы</h3>

<h4>Основные концепции</h4>
<ul>
  <li><strong>Type Erasure</strong> — механизм, позволяющий хранить значения произвольных типов без знания их конкретного типа на этапе компиляции.</li>
  <li><strong>Состояние</strong>:
    <ul>
      <li><code>has_value()</code> — проверяет, содержит ли <code>any</code> значение.</li>
    </ul>
  </li>
  <li><strong>Доступ к значению</strong>:
    <ul>
      <li><code>any_cast<T>(any)</code> — извлечение значения типа <code>T</code>.</li>
      <li><code>type()</code> — получение информации о типе хранимого значения.</li>
    </ul>
  </li>
</ul>

<h4>Конструкторы std::any</h4>
<table>
  <tr>
    <th>Конструктор</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>any()</code></td>
    <td>Создаёт пустой <code>any</code>.</td>
  </tr>
  <tr>
    <td><code>any(T value)</code></td>
    <td>Создаёт <code>any</code> с значением типа <code>T</code>.</td>
  </tr>
  <tr>
    <td><code>any(std::in_place_type_t<T>, Args... args)</code></td>
    <td>Создаёт <code>any</code> с конструкцией значения типа <code>T</code> на месте.</td>
  </tr>
</table>

<h3>Практические рекомендации</h3>
<ul>
  <li>Используйте <code>std::any</code> для хранения значений произвольных типов.</li>
  <li>Используйте <code>std::any_cast</code> для извлечения значений.</li>
  <li>Проверяйте тип перед извлечением с помощью <code>type()</code> или <code>has_value()</code>.</li>
  <li>Избегайте избыточного использования <code>std::any</code> — он может усложнить код и уменьшить производительность.</li>
</ul>

---
<h3>Заключение</h3>
<p>
<strong>`std::any`</strong> — это контейнер для хранения значений произвольных типов.
Он предоставляет механизм <strong>type erasure</strong>, позволяющий работать с данными без знания их конкретного типа на этапе компиляции.
</p>
