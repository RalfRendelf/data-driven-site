<h2>std::regex: Регулярные выражения в C++</h2>

<p>
<strong>`std::regex`</strong> — библиотека для работы с регулярными выражениями, введенная в C++11.
Она предоставляет средства для поиска, замены и валидации строк с использованием регулярных выражений.
</p>

---
<h3>Теоретические основы</h3>

<h4>Основные концепции</h4>
<ul>
  <li><strong>Регулярное выражение (std::regex)</strong> — шаблон для поиска в строках.</li>
  <li><strong>Совпадение (std::smatch)</strong> — результат поиска регулярного выражения в строке.</li>
  <li><strong>Итератор совпадений (std::sregex_iterator)</strong> — итератор для перебора всех совпадений в строке.</li>
</ul>

<h4>Класс std::regex</h4>
<p>
Класс std::regex представляет регулярное выражение.
Конструктор принимает строку с шаблоном и флаги:
</p>
std::regex pattern("pattern", std::regex_constants::flag_type flags);
<p>
Флаги регулярных выражений:
</p>
<ul>
  <li>std::regex_constants::ECMAScript — синтаксис ECMAScript (по умолчанию).</li>
  <li>std::regex_constants::basic — базовый синтаксис.</li>
  <li>std::regex_constants::extended — расширенный синтаксис.</li>
  <li>std::regex_constants::icase — игнорирование регистра.</li>
  <li>std::regex_constants::nosubs — отключение захвата подвыражений.</li>
</ul>

<h4>Класс std::smatch</h4>
<p>
Класс std::smatch хранит результаты поиска регулярного выражения.
Он предоставляет методы для доступа к совпадениям:
</p>
<ul>
  <li>smatch::size() — количество совпадений.</li>
  <li>smatch::str(n) — строка n-го совпадения.</li>
  <li>smatch::position(n) — позиция n-го совпадения.</li>
  <li>smatch::length(n) — длина n-го совпадения.</li>
</ul>

<h4>Функции для работы с регулярными выражениями</h4>
<table>
  <tr>
    <th>Функция</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td>std::regex_match</td>
    <td>Проверяет, соответствует ли вся строка регулярному выражению.</td>
  </tr>
  <tr>
    <td>std::regex_search</td>
    <td>Ищет первое совпадение регулярного выражения в строке.</td>
  </tr>
  <tr>
    <td>std::regex_replace</td>
    <td>Заменяет совпадения регулярного выражения в строке.</td>
  </tr>
</table>

<h3>Практические рекомендации</h3>
<ul>
  <li>Используйте std::regex_match для проверки соответствия всей строки шаблону.</li>
  <li>Используйте std::regex_search для поиска совпадений в строке.</li>
  <li>Используйте std::sregex_iterator для перебора всех совпадений.</li>
  <li>Помните, что регулярные выражения могут быть ресурсоёмкими — избегайте сложных шаблонов в критических участках кода.</li>
</ul>
