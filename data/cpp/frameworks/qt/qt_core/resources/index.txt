<h2>Resources System: Система ресурсов Qt</h2>

<p>
<strong>Система ресурсов Qt</strong> позволяет встраивать файлы (изображения, иконки, стили и др.) непосредственно в исполняемый файл приложения.
Это упрощает распределение приложения, так как все необходимые файлы включены в один бинарник.
</p>

---
<h3>Теоретические основы</h3>

<h4>Что такое система ресурсов?</h4>
<ul>
  <li><strong>Встраивание файлов:</strong> Файлы включаются в исполняемый файл во время сборки.</li>
  <li><strong>Доступ через QFile:</strong> Ресурсы доступны через стандартные классы Qt (<code>QFile</code>, <code>QDir</code>).</li>
  <li><strong>Кросс-платформенность:</strong> Работает на всех платформах, поддерживаемых Qt.</li>
</ul>

<h4>Как работает система ресурсов?</h4>
<ul>
  <li><strong>Файл ресурсов (.qrc):</strong> XML-файл, описывающий, какие файлы нужно встроить в приложение.</li>
  <li><strong>Компилятор ресурсов (rcc):</strong> Инструмент, который преобразует файл .qrc в C++ код.</li>
  <li><strong>Доступ к ресурсам:</strong> Ресурсы доступны через префикс <code>:</code> (например, <code>:/images/logo.png</code>).</li>
</ul>

---
<h3>Использование</h3>

<h4>Создание файла ресурсов (.qrc)</h4>
<p>
Файл .qrc описывает, какие файлы нужно встроить в приложение:
</p>
<pre><code>
resources.qrc
</code></pre>

<h4>Подключение файла ресурсов в проекте</h4>
<p>
В файле .pro или CMakeLists.txt нужно указать файл ресурсов:
</p>
<pre><code>
project.pro
</code></pre>

<h4>Доступ к ресурсам</h4>
<p>
Ресурсы доступны через префикс <code>:</code>:
</p>
<pre><code>
resource_access_example.cpp
</code></pre>

---
<h3>Расширенные возможности</h3>

<h4>Префиксы ресурсов</h4>
<ul>
  <li>Префиксы позволяют организовывать ресурсы в иерархической структуре.</li>
  <li>Доступ к файлам осуществляется через префикс (например, <code>:/icons/icon1.png</code>).</li>
</ul>

<h4>Динамическое добавление ресурсов</h4>
<ul>
  <li>Можно загружать ресурсы динамически во время выполнения с помощью <code>QResource</code>.</li>
</ul>
<pre><code>
dynamic_resource_example.cpp
</code></pre>

---
<h3>Практические рекомендации</h3>
<ul>
  <li>Используйте систему ресурсов для встраивания статических файлов в приложение.</li>
  <li>Организуйте файлы в логические группы с помощью префиксов.</li>
  <li>Избегайте встраивания больших файлов, если они не нужны в приложении.</li>
  <li>Используйте <code>QResource</code> для динамической работы с ресурсами.</li>
</ul>
