<h2>QThread: Потоки в Qt</h2>

<p>
<strong>QThread</strong> — класс для работы с потоками в Qt.
Позволяет выполнять код в отдельных потоках, что полезно для долгих операций, чтобы не блокировать основной цикл событий.
</p>

---
<h3>Теоретические основы</h3>

<h4>Что такое QThread?</h4>
<ul>
  <li>Класс для управления потоками выполнения.</li>
  <li>Каждый <code>QThread</code> имеет свой собственный цикл событий.</li>
  <li>Потоки в Qt не являются "облегчёнными" (lightweight) — каждый поток потребляет значительные ресурсы.</li>
</ul>

<h4>Как работает QThread?</h4>
<ul>
  <li>Создаётся объект <code>QThread</code>.</li>
  <li>В поток перемещается объект (worker), который будет выполнять работу.</li>
  <li>Поток запускается вызовом <code>start()</code>.</li>
  <li>Работа выполняется в методе <code>run()</code> или в слотах объекта worker.</li>
</ul>

---
<h3>Основные методы</h3>
<ul>
  <li><code>QThread::start()</code> — запускает поток.</li>
  <li><code>QThread::quit()</code> — завершает цикл событий потока.</li>
  <li><code>QThread::wait()</code> — ожидает завершения потока.</li>
  <li><code>QThread::isRunning()</code> — проверяет, выполняется ли поток.</li>
  <li><code>QThread::currentThread()</code> — возвращает текущий поток.</li>
</ul>

<h3>Расширенные возможности</h3>

<h4>Перемещение объектов между потоками</h4>
<ul>
  <li>Используйте <code>QObject::moveToThread(QThread*)</code> для перемещения объекта в другой поток.</li>
  <li>Объект должен быть создан в основном потоке, а затем перемещён в целевой.</li>
  <li>После перемещения все сигналы и слоты объекта будут обрабатываться в новом потоке.</li>
</ul>

<h4>Взаимодействие между потоками</h4>
<ul>
  <li>Используйте сигналы и слоты с <code>Qt::QueuedConnection</code> для безопасного взаимодействия между потоками.</li>
  <li>Избегайте прямого доступа к данным из разных потоков без синхронизации.</li>
</ul>

<h4>Обработка событий в потоках</h4>
<ul>
  <li>Каждый поток имеет свой цикл событий.</li>
  <li>Для запуска цикла событий в потоке используйте <code>QThread::exec()</code>.</li>

  <li>События, отправленные в поток, обрабатываются в его цикле событий (обработка событий в потоках).</li>
  <li>События, отправленные в поток, обрабатываются в его цикле событий.</li>
</ul>
  <pre><code>
qthread_exec_example.cpp
</code></pre>
---
<h3>Практические рекомендации</h3>
<ul>
  <li>Используйте worker-объекты вместо наследования от <code>QThread</code>.</li>
  <li>Не создавайте и не уничтожайте объекты из разных потоков.</li>
  <li>Используйте сигналы и слоты для взаимодействия между потоками.</li>
  <li>Избегайте блокирующих вызовов в потоках.</li>
  <li>Не забывайте останавливать потоки при завершении работы.</li>
</ul>
