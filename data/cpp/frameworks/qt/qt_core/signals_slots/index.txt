<h2>Signals and Slots: Механизм событий Qt</h2>

<p>
<strong>Сигналы и слоты</strong> — это уникальный механизм Qt для взаимодействия между объектами.
Он позволяет объектам обмениваться сообщениями без прямой зависимости друг от друга, что обеспечивает <strong>низкую связанность</strong> и <strong>гибкость</strong>.
</p>

---
<h3>Теоретические основы</h3>

<h4>Что такое сигналы и слоты?</h4>
<ul>
  <li><strong>Сигналы (<code>signals</code>):</strong>
    <ul>
      <li>События, испускаемые объектами при возникновении определённых ситуаций (например, нажатие кнопки, изменение текста).</li>
      <li>Объявляются в классе с макросом <code>signals:</code>.</li>
      <li>Не имеют реализации — только объявление.</li>
      <li>Могут быть испущены (<code>emit</code>) из любого места класса.</li>
    </ul>
  </li>
  <li><strong>Слоты (<code>slots</code>):</strong>
    <ul>
      <li>Методы, которые вызываются в ответ на сигналы.</li>
      <li>Объявляются в классе с макросом <code>slots:</code>.</li>
      <li>Могут быть обычными методами класса или лямбда-выражениями.</li>
    </ul>
  </li>
  <li><strong>Соединение (<code>connect</code>):</strong>
    <ul>
      <li>Установка связи между сигналом и слотом с помощью <code>QObject::connect</code>.</li>
      <li>Один сигнал может быть соединён с несколькими слотами.</li>
      <li>Один слот может быть соединён с несколькими сигналами.</li>
    </ul>
  </li>
</ul>

<h4>Как работает механизм?</h4>
<ul>
  <li><strong>Автоматическое соединение:</strong> При испускании сигнала автоматически вызываются все соединённые с ним слоты.</li>
  <li><strong>Асинхронность:</strong> Сигналы и слоты могут работать асинхронно (например, между потоками).</li>
  <li><strong>Типобезопасность:</strong> В Qt 5+ соединения проверяются на совместимость типов на этапе компиляции.</li>
</ul>

<h3>Синтаксис</h3>

<h4>Объявление сигналов и слотов</h4>
<pre><code>
signals_slots_declaration.hpp
</code></pre>

<h4>Соединение сигналов и слотов</h4>
<p>
Соединение осуществляется с помощью метода <code>QObject::connect</code>:
</p>
<pre><code>
signals_slots_connection.cpp
</code></pre>

<h4>Типы соединений</h4>
<table>
  <tr>
    <th>Тип соединения</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>Qt::AutoConnection</code> (по умолчанию)</td>
    <td>Автоматически выбирает тип соединения в зависимости от потоков.</td>
  </tr>
  <tr>
    <td><code>Qt::DirectConnection</code></td>
    <td>Слот вызывается сразу при испускании сигнала (синхронно).</td>
  </tr>
  <tr>
    <td><code>Qt::QueuedConnection</code></td>
    <td>Слот вызывается асинхронно через цикл событий.</td>
  </tr>
  <tr>
    <td><code>Qt::BlockingQueuedConnection</code></td>
    <td>Слот вызывается асинхронно, но блокирует поток отправителя до завершения.</td>
  </tr>
  <tr>
    <td><code>Qt::UniqueConnection</code></td>
    <td>Гарантирует, что соединение будет установлено только один раз.</td>
  </tr>
</table>

<h4>Разъединение сигналов и слотов</h4>
<p>
Для разъединения используется метод <code>QObject::disconnect</code>:
</p>
<pre><code>
signals_slots_disconnect.cpp
</code></pre>

<h3>Расширенные возможности</h3>

<h4>Сигналы и слоты между потоками</h4>
<ul>
  <li>По умолчанию (<code>Qt::AutoConnection</code>) Qt автоматически выбирает тип соединения в зависимости от потоков:
    <ul>
      <li>Если отправитель и получатель в одном потоке — <code>Qt::DirectConnection</code>.</li>
      <li>Если в разных потоках — <code>Qt::QueuedConnection</code>.</li>
    </ul>
  </li>
  <li>Для безопасной работы между потоками используйте <code>Qt::QueuedConnection</code>.</li>
</ul>

<h4>Лямбда-выражения как слоты</h4>
<p>
В Qt 5+ можно использовать лямбда-выражения в качестве слотов:
</p>
<pre><code>
signals_slots_lambda.cpp
</code></pre>

<h4>Сигналы с параметрами</h4>
<ul>
  <li>Сигналы могут передавать параметры в слоты.</li>
  <li>Типы параметров должны совпадать или быть совместимыми.</li>
</ul>
<p>
Пример:
</p>
<pre><code>
signals_slots_parameters.hpp
</code></pre>

---
<h3>Практические рекомендации</h3>
<ul>
  <li>Используйте сигналы и слоты для взаимодействия между объектами.</li>
  <li>Избегайте прямого вызова методов между объектами, если можно использовать сигналы/слоты.</li>
  <li>Используйте <code>Qt::QueuedConnection</code> для работы между потоками.</li>
  <li>Используйте лямбда-выражения для простых слотов.</li>
  <li>Не забывайте разъединять сигналы и слоты при уничтожении объектов.</li>
</ul>
