<h2>QObject: Базовый класс Qt</h2>

<p>
<strong>QObject</strong> — базовый класс для всех объектов в Qt, предоставляющий основные механизмы фреймворка:
<strong>систему сигналов и слотов</strong>, <strong>метаобъектную систему (MOC)</strong> и <strong>управление жизненным циклом</strong>.
</p>

---
<h3>Ключевые особенности</h3>

<h4>Жизненный цикл и родительство</h4>
<ul>
  <li><strong>Иерархия объектов:</strong> Каждый QObject может иметь родительский объект (<code>QObject*</code>).
    <ul>
      <li>Родитель управляет временем жизни дочерних объектов: при уничтожении родителя автоматически уничтожаются все его дети.</li>
      <li>Исключение: объекты, созданные в куче без родителя, должны освобождаться вручную.</li>
    </ul>
  </li>
  <li><strong>Управление памятью:</strong>
    <ul>
      <li>Если объект создан с родителем, он автоматически удаляется при уничтожении родителя.</li>
      <li>Если объект создан без родителя, его нужно удалять вручную (<code>delete</code>).</li>
    </ul>
  </li>
</ul>

<h4>Meta-Object System (MOC)</h4>
<ul>
  <li><strong>Макрос Q_OBJECT:</strong> Объявляет класс как часть метаобъектной системы.
    <ul>
      <li>Генерирует дополнительный код для поддержки сигналов/слотов, интроспекции и динамического приведения типов.</li>
      <li>Требует запуска <code>moc</code> (Meta-Object Compiler) во время сборки.</li>
    </ul>
  </li>
  <li><strong>Интроспекция:</strong> Возможность получения информации о классах и их методах во время выполнения.</li>
  <li><strong>Динамическое приведение типов:</strong> Использование <code>qobject_cast</code> для безопасного приведения типов.</li>
</ul>

<h4>Свойства (Q_PROPERTY)</h4>
<ul>
  <li>Макрос <code>Q_PROPERTY</code> позволяет объявлять свойства, которые могут использоваться в:
    <ul>
      <li>Qt Designer для настройки через интерфейс.</li>
      <li>Системе стилей (QSS).</li>
      <li>Метаобъектной системе для доступа через <code>QMetaObject</code>.</li>
    </ul>
  </li>
</ul>
<p>
Пример объявления свойства:
</p>

property_example.hpp
</code></pre>

<h4>Основные методы</h4>
<ul>
  <li><code>QObject::parent()</code> — возвращает родительский объект.</li>
  <li><code>QObject::setParent(QObject*)</code> — устанавливает родительский объект.</li>
  <li><code>QObject::children()</code> — возвращает список дочерних объектов.</li>
  <li><code>QObject::metaObject()</code> — возвращает метаинформацию о классе.</li>
  <li><code>QObject::sender()</code> — возвращает объект, отправивший сигнал.</li>
</ul>

---
<h3>Практические рекомендации</h3>
<ul>
  <li>Всегда используйте <code>Q_OBJECT</code> в классах, которые должны поддерживать сигналы/слоты.</li>
  <li>Используйте родительство для автоматического управления памятью.</li>
  <li>Избегайте циклических ссылок между объектами.</li>
  <li>Не создавайте QObject в стеке (только в куче).</li>
</ul>
