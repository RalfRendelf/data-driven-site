<h2>Qt Concurrent: Обзор</h2>

<p>
<strong>Qt Concurrent</strong> — модуль Qt для упрощения многопоточного программирования.
Он предоставляет высокоуровневые API для выполнения задач в пуле потоков без необходимости ручного управления потоками.
</p>

---
<h3>Архитектура</h3>
<ul>
  <li><strong>Пул потоков:</strong> Qt Concurrent использует глобальный пул потоков (<code>QThreadPool</code>), который управляет выполнением задач.</li>
  <li><strong>Асинхронное выполнение:</strong> Задачи выполняются асинхронно, не блокируя основной поток.</li>
  <li><strong>Интеграция с Qt:</strong> Полная интеграция с системой сигналов и слотов, а также с циклами событий.</li>
</ul>

<h3>Основные компоненты</h3>
<ul>
  <li><strong>QtConcurrent::run</strong> — асинхронный запуск функций.</li>
  <li><strong>QFuture & QFutureWatcher</strong> — отслеживание выполнения задач.</li>
  <li><strong>Параллельные алгоритмы</strong> — <code>map</code>, <code>filter</code>, <code>reduce</code>.</li>
  <li><strong>QThreadPool</strong> — управление пулом потоков.</li>
</ul>

<h3>Преимущества</h3>
<ul>
  <li>Упрощает многопоточное программирование.</li>
  <li>Автоматически управляет пулом потоков.</li>
  <li>Интегрируется с сигналами и слотами Qt.</li>
  <li>Поддерживает отмену задач.</li>
</ul>

<h3>Когда использовать?</h3>
<ul>
  <li>Для выполнения долгих операций в фоновом режиме.</li>
  <li>Для параллельной обработки данных.</li>
  <li>Для использования параллельных алгоритмов (map, filter, reduce).</li>
</ul>
