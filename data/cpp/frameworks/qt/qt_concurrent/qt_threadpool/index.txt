<h2>QThreadPool: Пул потоков Qt</h2>

<p>
<strong>QThreadPool</strong> — класс для управления пулом потоков в Qt.
Он позволяет выполнять задачи в отдельных потоках, используя доступные потоки из пула.
</p>

---
<h3>Теоретические основы</h3>

<h4>Что такое QThreadPool?</h4>
<ul>
  <li>Глобальный пул потоков, который управляет выполнением задач.</li>
  <li>Используется <code>QtConcurrent</code> и другими компонентами Qt.</li>
  <li>Автоматически управляет количеством потоков в зависимости от доступных ядер процессора.</li>
</ul>

<h4>Как работает QThreadPool?</h4>
<ul>
  <li>Задачи добавляются в пул с помощью <code>QThreadPool::start()</code>.</li>
  <li>Пул автоматически распределяет задачи по доступным потокам.</li>
  <li>Количество потоков можно настроить с помощью <code>QThreadPool::setMaxThreadCount()</code>.</li>
</ul>

---
<h3>Основные методы</h3>
<ul>
  <li><code>QThreadPool::globalInstance()</code> — возвращает глобальный экземпляр пула потоков.</li>
  <li><code>QThreadPool::start(QRunnable *task)</code> — запускает задачу в пуле.</li>
  <li><code>QThreadPool::setMaxThreadCount(int)</code> — устанавливает максимальное количество потоков.</li>
  <li><code>QThreadPool::maxThreadCount()</code> — возвращает максимальное количество потоков.</li>
  <li><code>QThreadPool::activeThreadCount()</code> — возвращает количество активных потоков.</li>
</ul>
