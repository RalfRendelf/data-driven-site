<h2>Дизассемблирование и анализ бинарников</h2>

<p>
Инструменты для <strong>дизассемблирования</strong> и анализа бинарников позволяют изучать скомпилированные программы на уровне машинного кода.
Это полезно для отладки, оптимизации и анализа безопасности.
</p>

---
<h3>Теоретические основы</h3>

<h4>Что такое дизассемблирование?</h4>
<p>
Дизассемблирование — это процесс преобразования машинного кода в ассемблерный код, который можно прочитать и проанализировать.
Основные инструменты для дизассемблирования в Linux:
</p>
<ul>
  <li><strong>objdump</strong> — утилита для отображения информации о бинарных файлах.</li>
  <li><strong>readelf</strong> — утилита для анализа ELF-файлов.</li>
  <li><strong>nm</strong> — утилита для просмотра символов в бинарных файлах.</li>
  <li><strong>strings</strong> — утилита для извлечения строк из бинарных файлов.</li>
</ul>

---
<h3>objdump</h3>

<h4>Что такое objdump?</h4>
<p>
<strong>objdump</strong> — утилита для отображения информации о бинарных файлах (объектных файлах, исполняемых файлах, библиотеках).
Она позволяет просмотреть:
</p>
<ul>
  <li>Дизассемблированный код.</li>
  <li>Секции бинарного файла.</li>
  <li>Символы и таблицы символов.</li>
  <li>Информацию о заголовках.</li>
</ul>

<h4>Основные флаги objdump</h4>
<table>
  <tr>
    <th>Флаг</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>-d</code></td>
    <td>Показывает дизассемблированный код.</td>
  </tr>
  <tr>
    <td><code>-D</code></td>
    <td>Показывает дизассемблированный код всех секций.</td>
  </tr>
  <tr>
    <td><code>-t</code></td>
    <td>Показывает таблицу символов.</td>
  </tr>
  <tr>
    <td><code>-h</code></td>
    <td>Показывает заголовки секций.</td>
  </tr>
  <tr>
    <td><code>-x</code></td>
    <td>Показывает заголовки всех секций.</td>
  </tr>
  <tr>
    <td><code>-S</code></td>
    <td>Показывает исходный код вместе с дизассемблированным.</td>
  </tr>
</table>

<h4>Примеры использования objdump</h4>
<pre><code>
objdump_example.sh
</code></pre>

---
<h3>readelf</h3>

<h4>Что такое readelf?</h4>
<p>
<strong>readelf</strong> — утилита для анализа ELF-файлов (Executable and Linkable Format).
Она позволяет просмотреть:
</p>
<ul>
  <li>Заголовок ELF-файла.</li>
  <li>Секции и их содержимое.</li>
  <li>Таблицу символов.</li>
  <li>Информацию о динамической линковке.</li>
</ul>

<h4>Основные флаги readelf</h4>
<table>
  <tr>
    <th>Флаг</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>-h</code></td>
    <td>Показывает заголовок ELF-файла.</td>
  </tr>
  <tr>
    <td><code>-S</code></td>
    <td>Показывает секции.</td>
  </tr>
  <tr>
    <td><code>-s</code></td>
    <td>Показывает таблицу символов.</td>
  </tr>
  <tr>
    <td><code>-d</code></td>
    <td>Показывает динамические секции.</td>
  </tr>
  <tr>
    <td><code>-l</code></td>
    <td>Показывает информацию о программных заголовках.</td>
  </tr>
</table>

<h4>Примеры использования readelf</h4>
<pre><code>
readelf_example.sh
</code></pre>

---
<h3>nm</h3>

<h4>Что такое nm?</h4>
<p>
<strong>nm</strong> — утилита для просмотра таблицы символов в бинарных файлах.
Она показывает символы (функции, переменные) и их адреса.
</p>

<h4>Основные флаги nm</h4>
<table>
  <tr>
    <th>Флаг</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>-g</code></td>
    <td>Показывает только глобальные символы.</td>
  </tr>
  <tr>
    <td><code>-u</code></td>
    <td>Показывает только неопределённые символы.</td>
  </tr>
  <tr>
    <td><code>-C</code></td>
    <td>Показывает символы в формате C++ (деманглирует имена).</td>
  </tr>
  <tr>
    <td><code>-n</code></td>
    <td>Сортирует символы по адресу.</td>
  </tr>
  <tr>
    <td><code>-v</code></td>
    <td>Сортирует символы по значению.</td>
  </tr>
</table>

<h4>Примеры использования nm</h4>
<pre><code>
nm_example.sh
</code></pre>

---
<h3>strings</h3>

<h4>Что такое strings?</h4>
<p>
<strong>strings</strong> — утилита для извлечения строк из бинарных файлов.
Она ищет последовательности печатаемых символов и выводит их.
</p>

<h4>Основные флаги strings</h4>
<table>
  <tr>
    <th>Флаг</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>-n &lt;min-length&gt;</code></td>
    <td>Указывает минимальную длину строки (по умолчанию 4).</td>
  </tr>
  <tr>
    <td><code>-t &lt;format&gt;</code></td>
    <td>Указывает формат вывода адресов (<code>d</code> — десятичный, <code>x</code> — шестнадцатеричный, <code>o</code> — восьмеричный).</td>
  </tr>
  <tr>
    <td><code>-a</code></td>
    <td>Сканирует весь файл, а не только секции с данными.</td>
  </tr>
</table>

<h4>Примеры использования strings</h4>
<pre><code>
strings_example.sh
</code></pre>

<h3>Практические рекомендации</h4>
<ul>
  <li>Используйте <strong>objdump</strong> для дизассемблирования и анализа секций.</li>
  <li>Используйте <strong>readelf</strong> для анализа ELF-файлов.</li>
  <li>Используйте <strong>nm</strong> для просмотра таблицы символов.</li>
  <li>Используйте <strong>strings</strong> для извлечения строк из бинарников.</li>
  <li>Комбинируйте инструменты для комплексного анализа бинарных файлов.</li>
</ul>

---
<h3>Заключение</h3>
<p>
Инструменты <strong>objdump</strong>, <strong>readelf</strong>, <strong>nm</strong> и <strong>strings</strong> — мощные утилиты для дизассемблирования и анализа бинарных файлов.
Они позволяют изучать скомпилированные программы на низком уровне, что полезно для отладки, оптимизации и анализа безопасности.
</p>
