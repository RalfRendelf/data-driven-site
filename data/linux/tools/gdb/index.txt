<h2>Отладка программ с помощью GDB</h2>

<p>
<strong>GDB</strong> (GNU Debugger) — мощный инструмент для отладки программ на C/C++ и других языках.
Позволяет анализировать выполнение программы, устанавливать точки останова, изучать значения переменных и стек вызовов.
</p>

---
<h3>Теоретические основы</h3>

<h4>Что такое GDB?</h4>
<p>
GDB — это отладчик, который позволяет:
</p>
<ul>
  <li>Запускать программы в пошаговом режиме.</li>
  <li>Устанавливать точки останова (<code>breakpoints</code>).</li>
  <li>Просматривать и изменять значения переменных.</li>
  <li>Анализировать стек вызовов.</li>
  <li>Отлаживать программы, которые уже завершились аварийно (<code>core dumps</code>).</li>
</ul>

<h4>Основные команды GDB</h4>
<table>
  <tr>
    <th>Команда</th>
    <th>Описание</th>
  </tr>
  <tr>
    <td><code>gdb &lt;program&gt;</code></td>
    <td>Запуск GDB с указанием программы.</td>
  </tr>
  <tr>
    <td><code>run [args]</code></td>
    <td>Запуск программы с аргументами.</td>
  </tr>
  <tr>
    <td><code>break &lt;location&gt;</code></td>
    <td>Установка точки останова на строке, функции или адресе.</td>
  </tr>
  <tr>
    <td><code>watch &lt;expr&gt;</code></td>
    <td>Установка наблюдения за выражением (<code>watchpoint</code>).</td>
  </tr>
  <tr>
    <td><code>next (n)</code></td>
    <td>Выполнение следующей строки (не заходит в функции).</td>
  </tr>
  <tr>
    <td><code>step (s)</code></td>
    <td>Выполнение следующей строки (заходит в функции).</td>
  </tr>
  <tr>
    <td><code>continue (c)</code></td>
    <td>Продолжение выполнения до следующей точки останова.</td>
  </tr>
  <tr>
    <td><code>print &lt;expr&gt;</code></td>
    <td>Вывод значения выражения.</td>
  </tr>
  <tr>
    <td><code>backtrace (bt)</code></td>
    <td>Вывод стека вызовов.</td>
  </tr>
  <tr>
    <td><code>info breakpoints</code></td>
    <td>Просмотр списка точек останова.</td>
  </tr>
  <tr>
    <td><code>delete &lt;n&gt;</code></td>
    <td>Удаление точки останова по номеру.</td>
  </tr>
  <tr>
    <td><code>quit (q)</code></td>
    <td>Выход из GDB.</td>
  </tr>
</table>

<h4>Типы точек останова</h4>
<ul>
  <li><strong>Обычные точки останова (<code>break</code>)</strong> — останавливают выполнение на заданной строке или функции.</li>
  <li><strong>Условные точки останова (<code>break ... if &lt;condition&gt;</code>)</strong> — останавливают выполнение только при выполнении условия.</li>
  <li><strong>Точки наблюдения (<code>watch</code>)</strong> — останавливают выполнение при изменении значения переменной.</li>
</ul>

<h4>Работа с core dumps</h4>
<p>
GDB может анализировать <strong>core dumps</strong> — файлы, содержащие состояние программы на момент аварийного завершения.
</p>
<pre><code>
gdb_core_example.sh
</code></pre>

<h4>Отладка многопоточных программ</h4>
<ul>
  <li>Используйте <code>info threads</code> для просмотра списка потоков.</li>
  <li>Используйте <code>thread &lt;n&gt;</code> для переключения на поток с номером <code>n</code>.</li>
  <li>Используйте <code>break &lt;location&gt; thread &lt;n&gt;</code> для установки точки останова в определённом потоке.</li>
</ul>

---
<h3>Практические рекомендации</h3>
<ul>
  <li>Компилируйте программы с флагом <code>-g</code> для включения отладочной информации.</li>
  <li>Используйте <code>break &lt;function&gt;</code> для установки точек останова на функциях.</li>
  <li>Используйте <code>watch</code> для отслеживания изменений переменных.</li>
  <li>Используйте <code>backtrace</code> для анализа стека вызовов при аварийном завершении.</li>
  <li>Используйте <code>info locals</code> для просмотра локальных переменных.</li>
</ul>

---
<h3>Заключение</h3>
<p>
<strong>GDB</strong> — мощный инструмент для отладки программ на C/C++.
Он позволяет анализировать выполнение программы, находить ошибки и оптимизировать код.
</p>
